# Orders system

## Структура и задание

Система поделена на следующие модули:
- `infrastructure.py`: Имитация работы с БД и внешними сервисами.
- `main.py`: Точка входа в приложение.
- `models.py`: Модели данных системы.
- `processor.py`: Основная бизнес-логика.
- `staff.py`: Система управления персоналом склада.

Почти в каждом модуле есть архитектурные ошибки, которые нужно исправить.



## Использование
Запуск системы:
```
python main.py
```
